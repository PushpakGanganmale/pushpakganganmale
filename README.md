## 🚀 Featured Projects

### 💳 InvoiceGenius — AI Invoice Management SaaS

A full-stack invoicing platform with AI-assisted invoice creation, payment processing, and business profile management.

**Tech Stack:** TypeScript · React · Node.js · Express.js · PostgreSQL · MongoDB · Razorpay · Clerk · Groq AI · Docker

**Features:**
- AI-powered invoice content generation using Groq API.
- Invoice creation, editing, deletion, and PDF export.
- Razorpay payment integration.
- Secure Razorpay Checkout signature verification.
- Webhook signature verification and idempotent payment processing.
- PostgreSQL transactions and payment ledger.
- MongoDB business profile management.
- Clerk authentication and owner-scoped invoice access.
- Compound database indexes and optimized queries.
- Jest and Supertest API testing.
- GitHub Actions CI/CD.

**Backend Architecture:**

```text
React + TailwindCSS
        |
     REST APIs
        |
Express + TypeScript
        |
  +-----+----------+
  |     |          |
PostgreSQL MongoDB  Services
  |     |          |
Invoices Business  Razorpay
Payments Profiles  Groq AI
Webhooks            Clerk
```
